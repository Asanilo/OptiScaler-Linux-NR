# Sky upstream sync, 2026-10-22

Upstream: `https://github.com/Skynizz/optiscaler-dlss5` (`sky/main` = `fc702f8c`,
2026-10-19). Our previous port reference was `591fd305` (2026-10-06), so this
round covers 31 upstream commits. Work is on `dev/sky-sync-20261022`, an
isolated worktree; the frozen NRBridge Helper at `713f8ac9` is untouched.

## Synced in this round

### 1. Edit-cache anti-ghosting and temporal updates

Source commits: `356180b5`, `24155b23`, `6aaf8e0c`, `44e4802d`, `acb1493e`,
`7151951b`, `f438d6ef`, `4478bafa`, `ae3ecb8c` (+ revert `3e5f23a7`),
`e68191a3`, `6e704e74`.

The cache implementation and its shader were advanced to Sky's final state:

- fingerprint/context validation, same-surface fill, guided filter and aging;
- noise-aware colour checks and anti-flicker trust weighting;
- motion-priority cadence, GPU budget, still-view hold and adaptive speed;
- anti light pop-in, soft refresh and the keyframe crossfade span;
- shared motion field, tiled despeckle/variance, quarter-size regional lows;
- luminance stability (`LowTemporal`) and the pulse/stage timing probes.

The local Linux/Proton ownership model was fused back in rather than dropped:

- `BeginFrame` reserves this recording's descriptor-heap slots before any
  dispatch (`kFrameDispatchBudget = 20`, 256-heap ring);
- `Pass` pins every resource it binds to the actual command-list recording;
- `Park` releases the owner immediately because the recording keeps the GPU
  copy alive;
- the statistics readback is fence-gated (`ReadbackReady`) and a busy ring
  drops that frame's counters (`statsDropped`) instead of overwriting a slot;
- `Status` keeps the local `interval`, `readbacksPending` and `statsDropped`
  fields used by the overlay and the GPU fixture.

The cache remains **off by default**. The main toggles are exposed in the NR menu
under `Sky 1.3 anti-ghosting`; the full set is also available as INI keys:
`CacheFingerprint`, `CacheContext`, `CacheFingerprintTolerance`,
`CacheSurfaceFill`, `CacheSoftRefresh`, `CacheGuided`, `CacheGuidedStrength`,
`CacheAging`, `CacheAgeHalfLife`, `CacheAgeNeutral`, `CacheAdaptiveSpeed`,
`CacheAdaptiveMin`, `CacheAntiPop`, `CacheAntiPopRate`,
`CacheMotionPriority`, `CacheBudgetMs`, `CacheStillMax`, `CacheStillHold`,
`CacheNoiseAware`, `CacheCrossfadeFrames`, `CacheDumpFrames`, `CacheAsync`,
`ShowStats`, `MotionFade*`.

### 2. Speckle cleanup before the upscaler

Source commit: `53a7f0a3`. Imported `shaders/checker_guard/` (CPU guard,
D3D12 pass, HLSL and precompiled shader) and wired it around the upscaler in
`NVNGX_DLSS_Dx12.cpp`: the cleaned render-resolution colour is handed to both
the pre-SR NR pass and the upscaler, then the game's colour is restored. Off by
default (`FGSpeckleCleanup`, `FGSpeckleCleanupStrength`, `FGSpeckleCleanupDebug`);
these three are INI/config-first and are not yet in the general menu.
The upstream `FGMeter::OnRealFrame()` call was intentionally not imported: the
synced frame-generation subsystem is not part of this fork.

### 3. Pre-SR reduced model / x8 preset

Source commit: `784542e8`. Added `PreSrReduced` and the work-scale rule: with
pre-SR, the model runs at the whole render resolution unless `PreSrReduced`
asks for `WorkingScale` there too. The 30-pass/style machinery and presets were
already present in this fork.

### 4. Region mask as a standalone post-pass

Source commit: `4fa6abe8`. Sky implements the mask inside its composition
shader. This fork's composition shader carries the local depth-plane and
motion-jitter corrections, so taking Sky's precompiled header would lose them.
Instead the mask is an independent compute pass:

- `shaders/region_mask/region_mask.hlsl`, compiled with DXC 1.9.2609 to
  `RegionMask_Shader.h`; `DlssNr_Shader.h` and `DlssNr_Shader_Vk` are untouched.
- `RegionMask_Dx12` copies the edited frame, reads the game's untouched frame
  and the depth guide, and writes the chosen region back.
- Modes: off, scenery only (the near character stays as the game drew it), or
  foreground only. Distance, edge softness, strength, the upright-surface test
  and a tint are config and menu controls.
- Runs after the fresh resolve, after a cache refresh and on cached frames;
  suspended for compare, debug views and captures.
- Off by default (`RegionMask`, `RegionMaskDistance`, `RegionMaskSoftness`,
  `RegionMaskStrength`, `RegionMaskIgnoreFloor`, `RegionMaskShow`).

## Already present, not re-implemented

- Direct NR PreUpscale/Pre-SR, typed/untyped parameter restoration and placement
  comparison (`DlssNr::EvaluateBeforeUpscale`, `NrPreUpscale.h`).
- DualFeature and the dual-enlarger path.
- Multipass: `kMaxPasses = 30`, per-pass style/tuning overrides and presets.
- Native DLSS-G/MFG diagnostics and `MfgUnlock` (Sky main removed
  `MfgUnlock.cpp` in favour of its own synced FG, so there was nothing to port).
- Linux/Vulkan/Proton adaptations: queue-fence ownership, Vulkan hooks and the
  native-Vulkan resize/device-change fixes, local depth/motion guide fixes.

## Deferred or blocked

- **DLSS 5 HDR exposure / preset reset** (`553e4ed9`): the 30-pass/style part
  is already present; the remaining composition-shader changes are blocked by
  the same shader-rebuild gap.
- **Synced FG / MFG** (`b4d97444`..`7955efa7`): a separate Windows DX12
  swapchain/frame-generation subsystem that conflicts with this fork's native
  DLSS-G and Proton path. Not merged; the existing native MFG path is retained.
- **Injected DLSS-G** (`de1c009d`): Windows/Streamline-specific fix for games
  without Streamline (RDR2); not applicable to the current Linux target.
- **Menu reorganisation** (`953da7a0`): cosmetic; the new cache and speckle
  options are config/INI-first for now.
