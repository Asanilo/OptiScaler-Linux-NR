# Sky edit-cache CPU core (experimental)

This is a host NumPy transcription of selected frozen Sky Capture(2), Reproject(1), Pyramid(3), Apply(4) expressions. It is not a replacement NR algorithm or a Vulkan implementation. No model, Wine, GPU, game or renderer IPC is loaded. Optional crossfade, stabilization, temporal filtering and despeckle are off; refresh blend / low gain / high gain are 1, manual white point 1, depth tolerance .1, color tolerance .5, high decay .97, forward depth, motion scale 1 in the explicitly aligned synthetic coordinate domain. These are named CPU fixture values, not new validated game settings.

Run `python3 poc/game_nr/sky-cache-cpu/build_cache_cpu.py` from this worktree. Output is confined to this directory's ignored out/build-history. The frozen lowres PE's source/case/build/out are not modified. Results separate original source pin, host checks and scope. NumPy float64 arithmetic tests equations and policies; it does not prove GPU float32 bit equivalence, shader speed, phase alignment or image quality.

The carried object is bounded log-ratio EDIT plus depth/luma/confidence/pyramid, not old whole-frame NR. Apply reads the current base and preserves its alpha bits. Capture uses the untouched current snapshot; owned_snapshot rejects explicitly edited input and copies arrays. The future native implementation must perform actual owned GPU copies before borrowed views are overwritten. No GPU copy/fence ownership is implemented here.

Whole lineage invalidity (wrong session/version, reset, non-increasing source, missing/nonconsecutive link, age over four) directly returns current SR bytes. The zero-edit wrapper also returns original bits, including negative RGB and signed zero. This intentionally wraps the original shader's max(original,0) identity behavior. A low per-pixel high-band confidence is different: original Sky's coverage-weighted, bilateral low pyramid can still fill that surface. No whole-cache rejection or strength reduction substitutes for it. The black NR answer fallback retains an actually valid carried edit as original Mode2 does; no private model parameter or new shader is introduced.

Every sparse model refresh is planned Reset=1, since per-game-frame MV does not cover skipped model evaluations. That model policy is separate from per-game-frame edit-history links. Four synthetic contiguous links are exercised, including known previous-minus-current translation and depth occlusion. The same P1 session contains four actual source frames 18645..18648, hence only THREE actual adjacent links. Their twelve exact assets are hashed/size checked and summarized, but their 1080-color/720-guide spatial reprojection is NOT_RUN: k_output/phase remain UNVERIFIED. No missing fourth predecessor link is fabricated. Synthetic movement provides a discriminating oracle, not proof that the real Quality guide domain is aligned.

Current milestone: CPU invariants only. Vulkan cache capture/reprojection/pyramid/apply, actual asynchronous delivery, GPU memory budget and playable latency remain NOT_RUN. The separate matched-runtime lowres fixture will determine whether its 720 model configuration functions and costs less; this CPU core does not assert that result.
