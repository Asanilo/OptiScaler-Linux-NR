# Q2 standalone controlled motion fixture

Only canonical `bbport-worktree/tools/nr_probe/q2_controlled/{fixture-spec.json,CASE-SCHEMA.md}` and six pinned case JSONs are accepted. No Q1 IPC, shared memory, game, SR or FG. This directory is additive; accepted Q1/C4 sources and assets stay readonly.

Offline build: from this directory, `python3 build_q2.py`. It checks all asset SHA/bytes, compiles/runs a native CPU-only six-case schema rejection check, and compiles `out/wine_q2_motion_fixture.exe`; no Wine/GPU is invoked. `out/build.json` records source pre/post, inherited exact runtime/SDK/tool/asset pins, raw compile logs and CPU-only gates. BCrypt is not used: Root verifies source asset SHA before launch; the fixture independently copies uploaded GPU images back and byte-compares exact Color/Depth/MV before every Evaluate.

Root-only runtime CLI: `wine_q2_motion_fixture.exe RUN_DIR_WINDOWS CASE_JSON_WINDOWS`, with a fresh private Wine prefix and pinned direct 64-bit ELF loader/preloader. Keep inherited child-only WINEDLLPATH, mscoree/mshtml disables, nvapi64=n;dxgi=n, DXVK_ENABLE_NVAPI=1, NVIDIA_WINE_DLL_DIR and trace diagnostics. No DLL copy, system/prefix policy change, dependency install, or full Proton start. Root runner holds the shared GPU flock and fixed 300s outer watchdog; approval gates the exact PE/source/build/dependencies and one case JSON.

The device/model/core stay resident for the case. Each of primary/repeat_primary/zero_mv/reverse_mv/reset_second creates an independent 1080 feature and observes its creation GPU fence. Two actual production encode/Evaluate/resolve frames use the requested guide extent and final MV scale args verbatim; Reset=1/0 except reset_second=1/1. A branch's feature is released only after its last observed GPU fence. No jitter setter, extra MV multiply, oracle truth/mask load, or algorithm rewrite.

Raw97 is poisoned with NaN; Output109 with -1234 before every Evaluate. Five readbacks per frame (actual uploaded source32F/depth32F/mv32F, model raw16F, resolved32F) are local CPU diagnostics, never a shared-transport claim. `run-result.json` retains exact canonical keys and partial failure state; `q2-fixture.log` records actual handles/ordinals, APIs, creation and frame fences, statistics and teardown. Exit2 denotes explicit functional/API failure; exit3 denotes unavailable/runtime/watchdog. GPU-unknown paths hold allocations and do not normal-release or destroy a device.

Budgets remain cold120s/frame30s/fence10s/outer300s. Phase is asset selection only. Functional execution PASS does not identify NR MV semantics, game phase, image quality, performance or shared transport. B's frozen CPU oracle decides behavior distinguishability; NR phase/absolute normalization remain UNVERIFIED unless supported by that separate analysis. Runtime is NOT_RUN until Root executes an approved case.

Own fixture/adapter text: GPL-3.0-or-later. Existing MIT fixture utilities, JSON header, Vulkan/NGX SDK headers and proprietary pinned model/runtime/PE are read-only dependencies; no runtime, model or generated executable belongs in a source commit.

Parameter application correction: `model_parameters` is the canonical **request echo**. The pinned forwarder `dlssnr_vk_evaluate` does not accept/set frame_ms, exposure or pre_exposure. Each is recorded in `parameter_application` as `HOST_FIXTURE_DECLARATION_NOT_SENT_TO_NR_API`, with the fourth key `runtime_default_values="UNVERIFIED"`; no runtime-default numeric value is asserted. Per-frame `evaluate_parameters` records only actual fixed-forwarder scalar arguments and its resource/subrect writes (Reset, DepthInverted, Intensity, Style, LocalStructure/LocalTone/SkinStructure, UseAutoMask and MVecScale). No ABI, fixed forwarder, model, shader or private setter is changed.
