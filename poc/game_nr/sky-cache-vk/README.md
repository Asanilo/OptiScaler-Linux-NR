# Owned Sky Vulkan cache fixture — BUILD_ONLY

The production Sky Capture2 / Reproject1 / Pyramid3 / Apply4 shader math is reused. This fixture owns its Vulkan images, buffers, descriptor sets, command buffer and finite fence. One managed slot serializes uploads, four cache dispatches, readback and actual fence completion. Two edit-history banks are resource ping-pong inside that one slot, not independent producer slots. No game renderer/native wire, DMA_BUF, NR create/Evaluate/resolve, NVAPI or DXGI is invoked. Model output is a saved successful lowres720 resolved image, or a declared synthetic edited image for a known-domain oracle. Capture requires origin==source at every refresh and is rejected before GPU initialization otherwise. This fixture does NOT implement asynchronous late-origin snapshot capture; that future path must preserve the original origin source and then catch up actual links.

Compile only: `python3 poc/game_nr/sky-cache-vk/build_cache_vk.py` in this worktree. glslang translates the generated HLSL, spirv-val validates Vulkan1.2 SPIR-V, reflection checks all scalar offsets/bindings and Shader-only capabilities, CPU checks cases/assets/schema negatives and known geometry oracle, then llvm-mingw creates out/wine_sky_cache_fixture.exe. Build never executes it. All generated shaders/SPIR-V/oracles/assets/PE/logs live only in this directory's ignored out, and build history is retained. Old lowres/P0/Q2/stable inputs are read-only and hash checked before/after.

Future CLI (NO RUN AUTHORIZATION): `wine_sky_cache_fixture.exe RUN_DIR_WINDOWS CASE_JSON_WINDOWS`. RUN_DIR must exist, be isolated and not contain run-result.json. Five compiled case JSONs are emitted under out/cases. No launcher or automatic run is provided. Budgets are cold120s / frame30s / GPUfence10s / wall300s. Unknown GPU completion means HOLD: no image/buffer/feature/device release may be claimed, and process exit is not proof of GPU completion. Normal cleanup requires the final actual fence before owned destruction.

Bindings are b0=0; sampled tN=N+1 (unused t9 stand-in=10); storage uN=N+13; separate linear sampler20. All used descriptors are bound. The original 39 four-byte scalars occupy bytes0..155; standalone gWholeValid is appended at byte156 in the original 256-byte allocation's padding. The original DlssNr_CacheCommon.h is unchanged. A generated patch precisely records bindings and the two guards: whole-lineage invalid Apply copies raw currentSR; effective zero edit returns the original pixel unchanged. The remaining production expressions are untouched. Scalar offset verification and resource formats are explicit; runtime device limits/format support/actual pipeline creation remain NOT_RUN.

Selected constants match the CPU core: WP1, exposure unknown/no texture exposure, forward-Z, MVscale1 in the named candidate coordinate domain, depth tolerance .1 / color tolerance .5 / high decay .97, refresh blend / low / high gains1, bilateral1. Optional crossfade/JBU/adaptive/temporal/stabilization/despeckle/debug are off. The compiled source still contains original unused modes, but fixture dispatch accepts only 1/2/3/4. A low pixel confidence does not invalidate the whole edit: the original low-frequency pyramid can fill holes at full low gain. Whole reset/invalid session/version/missing or stale link/age>4 instead preserves currentSR exactly until a new saved refresh.

Known synthetic cases have one anchor plus four explicitly recorded previous-minus-current links, with CPU float64 equations generating float32 expected outputs. They cover translation, signed-zero/negative zero-edit identity, whole invalid reset, depth occlusion/low-band behavior. A future GPU comparison tolerance is predeclared as 3e-5 + 3e-4*abs(reference), with alpha and invalid/zero identity checked separately bitwise. This is a numerical CPU/GPU equivalence test, not a quality test.

Saved-real case pins first-run lowres720's source/edited/depth/MV dumps and provenance. It contains four actual source frames 18645..18648, only THREE actual adjacent links. Color/edited/output remain1080; guide depth/MV720. phase_status=UNVERIFIED_REAL_GUIDE_DOMAIN, no fabricated expected oracle and no spatial jitter correction. Zero jitter_delta_uv means phase_correction=none for this candidate, not that actual game jitter was zero or its output phase identified. Stored MV remains previous-minus-current render pixels with scale1 as source-backed candidate, not a validated NR/cache phase conversion. Images originate from untouched saved SR; Apply never feeds its result back as input or model snapshot.

Each future frame logs current_source separately from effect_origin/age/history version, source/edited GPU upload equality, actual fence serial, finite/written/alpha counters and three independent local dumps (current source, composed output, edit). Shader/GPU runtime, real phase, game response and playable performance are NOT_RUN/UNVERIFIED.
